### Redis

1. Redis được viết tắt cho remote dictionary server.
2. Redis là một hệ thống cơ sở dữ liệu NoSQL, tức là redis không lưu dữ liệu rồi chia theo cột như các SQL thông thường mà sẽ lưu dữ liệu dưới dạng key-value hoạt động theo cơ chế NoSQL.
3. Redis được lưu trên bộ nhớ RAM nên việc ghi và đọc dữ liệu nhanh đáng kể nên sẽ giúp được hệ thống chịu tải được nhiều Request cùng lúc và một cách dễ dàng.
4. Redis có thể được dùng trong việc lưu dữ liệu đệm, quản lý phiên đăng nhập, giới hạn lượt gọi API
